# Verilog-HDL Digital Design & RTL Verification Portfolio (360+ Modules) | Mirpouria Mousavi Sarkandi

Welcome to my digital hardware design repository. This comprehensive archive showcases **360 structured RTL and switch-level hardware modules** written in **Verilog-HDL**, covering everything from CMOS transistor-level circuits to multi-module hierarchical datapaths and simulation testbenches.

---

## 📂 Repository Architecture (8 Specialized Modules)

### 1. Transistor / Switch-Level CMOS Modeling (`01-Transistor-Switch-Level-CMOS`)
* **Core Concepts:** CMOS logic design using primitive switches (`nmos`, `pmos`, `cmos`), transmission-gate multiplexers, and AOI logic cells with `supply1`/`supply0` rails.

### 2. Gate-Level Structural Primitives (`02-Gate-Level-Structural`)
* **Core Concepts:** Structural hardware modeling using primitive gates (`and`, `or`, `xor`, `xnor`, `bufif1`) combined with parameterized `generate` loops for ripple-carry adders, comparators, and parity trees.

### 3. Dataflow & Parameterized Arithmetic (`03-Dataflow-and-Arithmetic`)
* **Core Concepts:** Carry-Lookahead Adders (CLA), 8-operation ALUs, barrel shifters, Gray-to-Binary converters, and priority encoders across 4-bit to 64-bit architectures.

### 4. Clocked Registers, Pipelining & Memory (`04-Clocked-Registers-and-Pipelines`)
* **Core Concepts:** Synchronous sequential logic (`posedge clk`), universal shift registers, pipelined Multiply-Accumulate (MAC) DSP units, dual-port RAMs, and LFSR scramblers.

### 5. Mathematical, Exponential & DSP Accelerators (`05-Math-Exponential-and-DSP`)
* **Core Concepts:** Fixed-point hardware approximation stages for exponential mathematical functions ($e^x$) and high-speed arithmetic pipelines.

### 6. Finite State Machines & Bus Controllers (`06-FSM-and-Bus-Controllers`)
* **Core Concepts:** Multi-state FSM controllers for communication and bus interfaces (`UART`, `SPI`, `I2C`, `AXI-Lite`, `DMA`, Round-Robin Arbiters, and PWM generators).

### 7. Hierarchical Multi-Module Systems (`07-Hierarchical-Multi-Module-Systems`)
* **Core Concepts:** Top-level SoC datapath integration connecting modular sub-blocks (ALUs, control units, and clocked register stages) via internal buses.

### 8. Functional Simulation & Testbenches (`08-Simulation-and-Testbenches`)
* **Core Concepts:** Automated verification testbenches (`timescale 1ns/1ps`) with clock generation, stimulus sequences, and `$display`/`$finish` verification checks.
